# SIH 2026 Problem Statement Intelligence (Learning Project)

This project was developed as a **hands-on exercise** to gain practical experience in Natural Language Processing (NLP).  
It uses a dataset of Smart India Hackathon 2026 problem statements to explore text similarity, dimensionality reduction, and interactive visualization.



##  Purpose
- Practice applying **TF-IDF** for text vectorization.
- Understand **cosine similarity** for recommendation tasks.
- Experiment with **Truncated SVD** for dimensionality reduction and visualization.
- Gain experience building interactive dashboards with **Streamlit** and **Plotly**.

**Note**: This project is for **educational purposes only**.  
The dataset and models are used solely to practice NLP workflows, not for production deployment.


# Features
- Dataset overview with key metrics.
- Distribution of Software vs Hardware problems across themes.
- 3D visualization of problem statements using SVD.
- Simple recommendation engine based on textual similarity.
